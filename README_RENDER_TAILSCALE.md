# Подключение Render к базе на Mac через Tailscale

Это дополнение к существующему проекту, а не полный проект. Локальные Dockerfile и compose.yaml заменять не нужно.

## 1. Mac уже настроен

Адрес Mac: 100.69.20.118. Tailscale Serve направляет TCP 5433 на 127.0.0.1:5433.
Оставляйте Mac включённым, без сна, с интернетом, Tailscale и работающим Docker с PostgreSQL. Не запускайте docker compose down -v: это удаляет тома.

## 2. Добавьте файлы в GitHub

Распакуйте архив. Добавьте Dockerfile.render и render_tunnel.py в тот же каталог репозитория, где находятся requirements.txt, requirements-ml.txt и папка app. В GitHub можно использовать Add file → Upload files → Commit changes.

Не загружайте .env, пароли и ключи. Убедитесь, что .env и .env.* исключены в .dockerignore: Dockerfile копирует содержимое проекта в образ.

## 3. Создайте ключ Tailscale

В том же аккаунте, к которому подключён Mac, откройте https://login.tailscale.com/admin/settings/keys и создайте Auth key.
Включите Reusable (повторное использование) и Ephemeral (временное устройство). Если в сети требуется одобрение устройств, включите Pre-approved либо одобрите устройство вручную.

Повторное использование необходимо: Render может перезапускать контейнер, а состояние клиента хранится только в памяти. У ключа есть срок действия; после истечения замените его в Render. Не отправляйте ключ в чат или GitHub.

## 4. Настройте сервис на Render

Откройте существующий List_pgadmin → Settings. Укажите Dockerfile Path: ./Dockerfile.render относительно корня сборки. Docker Command оставьте пустым, чтобы использовался CMD из Dockerfile. Если поле не позволяет очистить команду, задайте python render_tunnel.py.

В Environment добавьте или измените:

| Имя | Значение |
| --- | --- |
| TAILSCALE_AUTHKEY | Новый Auth key из Tailscale |
| TAILSCALE_DB_HOST | 100.69.20.118 |
| DATABASE_URL | postgresql+psycopg://docsearch:ВАШ_ПАРОЛЬ_БД@127.0.0.1:15432/document_search |
| SESSION_SECRET | Существующий секрет сессий Render, минимум 32 символа |
| COOKIE_SECURE | true |

ВАШ_ПАРОЛЬ_БД замените действующим паролем PostgreSQL на Mac. Его менять не требуется. Если пароль содержит специальные символы URL, закодируйте их в части пароля (например @ → %40).

127.0.0.1:15432 в DATABASE_URL указан намеренно: это локальный посредник внутри контейнера Render, который передаёт соединение на Mac 100.69.20.118:5433. Локальный .env на Mac не меняйте.

Сохраните настройки и запустите сборку последнего коммита (Manual Deploy → Deploy latest commit). Само сохранение без развёртывания не запускает новый код.

## 5. Проверьте Logs

При успешном соединении появятся строки:

    Tailscale подключён; проверяем PostgreSQL на Mac
    PostgreSQL на Mac доступен; запускаем сайт

Затем должен запуститься Uvicorn. Откройте https://list-pgadmin.onrender.com и войдите под пользователем из базы на Mac.

Если вход Tailscale не выполнен: проверьте ключ, его срок и одобрение устройства. Если PostgreSQL недоступен: проверьте Docker на Mac, Serve, пароль и правила доступа Tailscale — устройству Render нужен доступ к Mac на TCP 5433. Правила всей сети для этого сбрасывать не нужно.

## Границы этого дополнения

Оно подключает существующую базу данных. Миграции и worker на Render автоматически не запускаются. Схема и данные на Mac не пересоздаются.

Исходные файлы документов остаются на Mac в /data/uploads. Туннель PostgreSQL не передаёт файловое хранилище: скачивание этих оригиналов на Render и обработка новых файлов, загруженных через Render, требуют отдельной настройки хранения. До её выполнения загружайте документы локально на Mac; скачивание оригиналов выполняйте через локальный сайт. Обработчик на Mac может индексировать локальные загрузки, а записи и векторы будут доступны Render через базу.

Для поиска приложению на Render также нужны модель и достаточная оперативная память. Это дополнение не уменьшает потребление памяти моделью.

## Проверки и откат

Локально проверены 6 тестов: конфигурация, защита сообщений от вывода пароля, передача двоичных данных, полузакрытие TCP, параллельные соединения и остановка соединений. Для запуска: python -m unittest discover -s . -p test_render_tunnel.py -v.

Сборка Docker и реальное соединение Render—Tailscale—PostgreSQL здесь не проверены; их результат подтвердят логи после развёртывания.

Для возврата к прежнему запуску Render укажите Dockerfile Path ./Dockerfile, очистите Docker Command и выполните развёртывание. При этом старая конфигурация DATABASE_URL должна быть восстановлена отдельно. Локальный проект на Mac это дополнение не меняет.

Документация: https://render.com/docs/docker ; https://tailscale.com/docs/concepts/userspace-networking ; https://tailscale.com/docs/reference/tailscale-cli ; https://tailscale.com/docs/features/access-control/auth-keys .
