# Результаты проверки первой версии

Проверено 20 октября 2026 года.

- Python 3.12: 52 теста прошли, ошибок нет. Одно предупреждение о deprecated-алиасе AnyIO внутри Starlette TestClient.
- Интеграционные проверки выполнены с PostgreSQL 18.6 в PGlite через PostgreSQL wire protocol и pgvector 0.8.7. Это не отдельный нативный сервер PostgreSQL 15.
- Проверены создание схемы, повторный запуск миграции, принятие существующей совместимой схемы с сохранением данных и отказ при расхождении структуры.
- Проверены пароли, вход/выход, CSRF, роли, отзыв доступа, изоляция коллекций при поиске и скачивании, ограничение попыток входа и размера запроса.
- Проверены загрузка, обработка, повторная обработка, удаление документов, три режима поиска, разбиение текста и извлечение TXT/DOCX/PDF.
- Отдельный тест использовал настоящую модель intfloat/multilingual-e5-small с 384-мерными векторами; SHA модели зафиксирован в app/embeddings.py.
- В Chromium проверены вход, архив, настоящий поиск по смыслу, просмотр документа, страницы загрузки и управления. Проверена мобильная ширина 390 px без горизонтального переполнения страницы.

## Обновление: вход и регистрация

- Добавлена страница /register и переходы между входом и регистрацией.
- Проверены создание читателя без прав на коллекции, нормализация логина, хеширование пароля, повтор пароля, занятый логин без изменения старого аккаунта, CSRF и отдельный лимит регистрации.
- В Chromium проверены регистрация, ошибка повторного пароля, автоматический вход, выход и повторный вход; макеты 1440 и 390 px.
- Конфигурация Compose теперь собирает общий образ только через web. Dockerfile нормализует права исходников для appuser. Это исправления по ошибкам запуска на macOS; запуск обновлённого Docker-образа в среде разработки по-прежнему не выполнен.

## Обновление: общие коллекции

- Миграция 0002 добавляет access_level с default private и CHECK; повторный запуск не меняет версию повторно.
- Проверены сохранение документов и персональных разрешений при переходе с 0001, закрытость старых коллекций, доступ нового читателя без персональных разрешений.
- Проверены категории и коллекции в фильтрах, лексический/векторный/гибридный поиск, прямой просмотр и скачивание, запрет гостям, права администратора и CSRF при смене видимости.
- Закрытие общей коллекции немедленно отзывает общий доступ; персональные разрешения сохраняются и продолжают работать.
- В Chromium проверены сохранение видимости администратором и регистрация нового читателя с доступом только к общей коллекции. Макеты 1440/390 px проверены без переполнения страницы.

## Обновление: смена роли

- В таблицу пользователей добавлены выбор роли и кнопка сохранения; собственная роль администратора недоступна для изменения.
- Проверены повышение/понижение reader/editor/admin, применение в существующей сессии, сохранение пароля и персональных разрешений, запреты читателю/редактору/гостю, неверная роль, отсутствующий пользователь и CSRF.
- В Chromium проверены изменение роли администратором, сохранённое значение, мобильный макет 390 px и появление загрузки у повышенного до редактора пользователя.

## Что ещё требуется проверить на целевом компьютере

Docker Engine в среде разработки отсутствовал: сборка образов и запуск Docker Compose не выполнялись. Конфигурация Compose разобрана и проверена как YAML; успешная сборка контейнеров этим не подтверждается.

Нативный запуск на macOS Apple Silicon с Homebrew PostgreSQL 15 и запуск контейнеров на этой архитектуре ещё не проверены. Пошаговые команды для обоих вариантов приведены в README.md. Перед подключением миграций к существующей базе сохраните резервную копию.

Удалённый доступ и HTTPS не настроены. Первая версия предназначена для локального запуска. Качество поиска на пользовательском корпусе и нагрузочные характеристики ещё не измерялись.
